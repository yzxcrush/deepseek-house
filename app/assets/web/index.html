          插件说明
          
在输入框以 / 开头可调用插件命令；启用插件的工具会通过 function calling 暴露给模型（最多 3 轮）。外部插件只在你主动安装后才执行，请只安装可信来源的代码。

还没有智能体预设

          点下方按钮新建预设，预设会出现在新建会话的「选择智能体」弹层里。
        


        

          
        


        

          智能体预设
          
预设包含名称、简介与系统提示词。新建会话时可选择预设，该会话的请求会使用预设的系统提示词与模型。内置预设也可以编辑或删除。

工具调用记录

        

        
      


      

        

        

          
          
还没有工具调用记录

          原生工具（读文件 / 写文件 / 执行命令等）每次执行都会记录在这里。
        

        

          关于审计
          
审计记录保存在本机 SQLite（audit.db），包含时间、工具名、参数、结果与是否经过确认。被拒绝的调用也会记录。

        

      

    


    
    

      

        
        

          
MCP 服务器

          
管理外部工具服务器

        

        
      


      

        
已配置的服务器

        


        

          
          
还没有 MCP 服务器

          在 Termux 运行 MCP Server 后，填入地址 http://127.0.0.1:8787/mcp 即可连接。
        


        

          
        


        

          MCP 说明
          
MCP（Model Context Protocol）把 Termux 侧的工具（打包 APK、反编译、Gradle 构建、列工作区等）接入模型。服务器只监听本机回环地址，Token 与配置只保存在本机。连接成功后，工具会出现在模型的可用工具列表中。

          
http://127.0.0.1:8787/mcp

        

      

    


    
    

      

        
        

          
插件市场

索引来源

        

          

            索引 URL
            
            仅支持 https；索引格式 {version:1, plugins:[{id,name,version,author,description,url,sha256,hmac,tags}]}。
          

          

            
          

        


        
可用插件

        


        

          
          
还没有市场插件

          填入 https 索引地址并「拉取索引」，或在插件页从本地安装 .js / .json 插件。
        


        

          关于插件市场
          
市场只接受 https 索引与下载地址；安装前会校验 sha256 与 HMAC 签名，校验失败不会写入。外部插件与本地插件一样在本机 WebView 沙箱内运行，请只安装可信来源。

会话摘要

        

        

          
还没有会话摘要

          上下文超过预算 80% 时，较早的消息会被压缩成摘要保存在这里。
        


        

          上下文压缩
          
发送前按字符估算 tokens（约 chars/3.5）；当会话超过上下文预算（默认 24000 字符）的 80% 时，保留最近消息并把更早内容压缩为摘要。压缩后会在气泡上方提示「已压缩 X 条历史」。

          
当前压缩阈值：80%
